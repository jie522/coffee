# 豆豆手沖帳

可愛的手沖咖啡紀錄 App，記錄每一支咖啡豆的研磨刻度與沖煮方法。

固定器具：**30g 豆量 · Comandante C40（Red Clix 紅軸）· HARIO V60 玻璃濾杯**

## 功能

- **豆櫃**：每支豆子的 C40 紅軸 clicks、水溫、粉水比、沖煮次數與平均評分
- **配方頁**：預備作業、5 段沖煮步驟（磨粉／悶蒸／第 1–3 段注水）、風味預期、滋味微調
- **配方產生**：依焙度與處理法快速估算；在 Claude 中開啟時可請 Claude 依 SCA 萃取理論設計
- **沖煮計時器**：每段提示目標累計克數，換段時嗶一聲
- **記一杯**：評分、實際刻度、水溫、總時間與心得
- **咖啡知識小卡**：器具、萃取、焙度、處理法、保存、豆種

## 使用

直接用瀏覽器開啟 `index.html`，或開啟 GitHub Pages。單獨開啟時資料存在該裝置的瀏覽器（localStorage）；
在 Claude Artifact 中開啟時資料會同步到 Claude 帳號，並可使用 Claude 生成配方。
